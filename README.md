# Login and Signup Slider with React

This is a single-page UI component with Login and Signup options.

## How to build:

- Make sure you have latest version of Node installed
- Create a React app using
  ```
  create-react-app <name-of-the-project>
  ```
- Import the necessary hooks
- Install and include Tailwind to the project. Follow the steps [here](https://tailwindcss.com/docs/installation)
- Background and icons imported from [SVGBackgrounds](https://www.svgbackgrounds.com/)
- This project also uses i18n for all texts and translations(if any). Install using ``` npm i i18n  ``` and follow these [steps](https://react.i18next.com/getting-started) to integrate it to your React project

## Usage

Use  ``` npm run start ``` to run and view it locally in 'localhost:3000'


Check out the page [here](https://react-slider-ten.vercel.app/)

## Docs

**React** - JS library ideal for building dynamic user interfaces and offers great flexibilty over code.


**React hooks** - To allow functional components to have access/update to state and other feature. 'useState' hook takes 2 arguments - state variable and a state method (which is used to update the state var)
```
const [name,setName] = useState('');

```


**i18n** - Internationalization framework built in and for JS. Used for translations rather than hard-coded text. Also has interpolation, formatting, plugins for detecting user language and many more features. Check out more [here](https://www.i18next.com/)
